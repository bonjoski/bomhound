## Overview

**Bomhound** is a high-performance CycloneDX Software Bill of Materials (SBOM) legal enrichment engine. It resolves upstream package license texts, parses author copyright notices, and resolves vanity import URLs to ensure open-source release compliance without external SaaS dependencies.

This directory provides task-oriented recipes for common SBOM compliance workflows.

---

## 📚 Recipe Catalog

| Recipe | Problem Addressed | Primary CLI Commands | Standard |
| :--- | :--- | :--- | :--- |
| **[01. CycloneDX Legal License Enrichment](01-sbom-license-enrichment.md)** | Enrich bare SBOMs with complete license texts and author copyright declarations. | `bomhound --input bom.json --output enriched.json` | CycloneDX v1.5 / v1.6 |
| **[02. Vanity Import URL Resolution](02-vanity-url-resolution.md)** | Map vanity URLs (`go.uber.org/zap`, `gopkg.in/yaml.v3`) to canonical upstream Git repositories to locate LICENSE files. | `bomhound --config .bomhound.yaml` | Git Vanity Resolvers |
| **[03. GitHub Actions In-Place Release Pipeline](03-github-actions-release-pipeline.md)** | Automatically enrich SBOMs generated by Syft or Trivy in-place during release workflows. | `bomhound --in-place bom.json` | CI/CD Release Pipeline |
